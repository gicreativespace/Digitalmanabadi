# Parent section

Own Parent login, linked-child access and parent-facing attendance, diary, homework and notices.

- `parent-section.js` owns the current Parent–Student linking workflow.
- `dashboard.js` owns the linked-student dashboard summary.
- Parent login/linking still uses browser-local preview data; it is not verified against live student records or shared across devices.

Keep student/guardian information private and extract further screens only with school-scoped authorization and tested data access.
