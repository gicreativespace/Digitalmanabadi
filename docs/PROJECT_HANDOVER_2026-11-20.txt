6. TEACHER LOGIN / SECRET CODE RULES
============================================================

- Teacher ID format: YYNN (example 2601).
- Login ID format: 2601@dagguluruschool.in.
- Fixed number: 919720.
- DOB is converted to DDMMYY.
- Secret/Login code = 919720 minus DOB(DDMMYY).
- Example DOB 29/04/1991 -> DDMMYY 290491 -> code 629229.
- Six-digit code is used as Firebase Auth password and Teacher Secret Code.
- Teacher profile stores the Secret Code in Firestore.
- Existing teacher missing Secret Code may have it calculated and saved before Auth provisioning.
- Firebase Email/Password provider must be enabled in Firebase Console.
- Firebase Auth default minimum password length is six; a stricter Password Policy may reject numeric-only passwords.
- Existing Firebase Auth passwords cannot be retrieved. Existing account reuse only happens if the approved code successfully signs in.
- Do not delete or reset existing accounts.
- The six-digit Firebase password and four-digit local Teacher PIN are separate workflows.
- Note: DOB-derived code is weak and should not be represented as strong security.
